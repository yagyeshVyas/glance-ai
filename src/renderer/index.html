Notes Glance keeps between chats: screen analyses, recaps and condensed previous conversations. Edit or delete any note here; deleting is permanent on the next save.

Capture and privacy

Capture exclusion is Windows' own privacy flag: screen shares that honour it leave the panel out. It is not a proctoring bypass, and it does not hide the process or the window from an enumerating tool.

Screenshots are capped at 1920 px on the long edge and five per question, and never written to disk. A frame can still contain notifications, names or other people's data — review the thumbnails before asking.
